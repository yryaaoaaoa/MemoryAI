# 对话中的知识库检索开关

AI 问答输入框上方提供“知识库检索”开关。默认关闭，用户开启后才在发送问题时检索知识库；同一页面的当前会话保持选择，切换会话、新建会话和刷新页面恢复关闭。生成回答期间开关不可修改，避免与正在处理的请求状态混淆。

服务器 `RAG_ENABLED` 继续表示知识库功能是否可用。线上保留 `true`，知识库管理、检索配置等功能保留；关闭全局功能时页面隐藏开关。

`POST /api/agent/chat/stream` 新增可选布尔字段 `useKnowledgeBase`：

- 缺省或 `false`：直接使用问题、历史、笔记背景与简历上下文，不调用知识库搜索，也不添加知识库回答模板。
- `true`：调用既有检索流程，使用检索内容构造回答提示词。
- 非布尔值：返回 400；全局检索不可用时显式请求检索返回 503。两项校验均在保存本轮用户消息前执行。

这是请求级开关，无数据库迁移，也不删除已有知识库或 Elasticsearch 数据。旧客户端不发送该字段时按关闭处理。

验证包括开关前后发送值、全局关闭、会话切换、手机与键盘操作、实际模型请求中有无知识库提示词、未开启时检索工具零调用，以及已有流式消息和学习笔记回归。通过现有 CI/CD 发布，无需修改服务器 `.env`。
