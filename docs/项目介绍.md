# MemoryAI — 智能求职备考平台

## 定位

AI 驱动的求职备考助手，帮助开发者通过「刷题 + 模拟面试 + AI 问答」三个维度准备技术面试。用户上传简历、导入知识库文档，系统基于 RAG（检索增强生成）技术理解用户的技术背景，提供个性化出题和面试评估。

---

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite 8 + Pinia + Element Plus |
| 后端 | Java 17 + Spring Boot 3.2.12 + MyBatis-Plus + Spring Security |
| 数据库 | MySQL（业务数据）+ Redis（会话/缓存）+ Elasticsearch 8.x（向量+全文检索） |
| AI | DeepSeek API（LLM 对话/出题/评估）+ SiliconFlow BGE-m3（Embedding）+ PaddleOCR |

---

## 架构概览

```
前端 (Vue 3)                    后端 (Spring Boot)
┌─────────────┐                ┌──────────────────────────────────────┐
│  DefaultLayout               │  bootstrap (启动入口)                  │

│  ├─ 模拟面试     ←→ REST →   │  ├─ rag (聊天会话/RAG 检索)            │

│  ├─ 简历解析     ←→ REST →   │  ├─ infrastructure (ES/Redis/User)   │
```

## 页面 & 用户流程

### 1. 登录/注册 (`/login`)

- 支持登录和注册切换，密码最小 6 位
- 认证方式：Session-Based（Spring Session + Redis），非 JWT
- 登录成功跳转 `/ask`

### 2. AI 问答 (`/ask`) — 核心功能

**用户流程：** 选择知识库 → 输入问题 → AI 流式回答（SSE）+ 显示引用来源

- 侧栏展示历史会话列表，可切换或删除
- 输入框支持回车发送，回答以 Markdown 流式渲染
- AI 会自动检索关联知识库的文档切片，在回答中标注引用
- 可关联简历，让 AI 结合简历背景回答问题
- 会话历史自动压缩（滑动窗口 + 摘要），支持长对话
- 显示 token 用量

**交互细节：**
- 回答逐字流式输出（SSE），带打字机效果
- 引用来源以卡片形式展示在回答下方
- 热门问题引导（预设问题列表）
- 支持中止生成（AbortController）

### 3. 刷题 (`/quiz`) — 三大子面板

#### 3a. 出题刷题

**用户流程：** 选择知识库 → 配置难度/题数 → 逐题作答 → 查看结果

- STEP 1 - 选题配置：勾选一个或多个知识库，选择难度（简单/中等/困难/混合），设定题目数量，可选知识点筛选
- STEP 2 - 答题界面：显示题目和 ABCD 选项，选择后自动提交 → 即时显示对错、正确答案、解析 + 进入下一题
- 右上角计时器，显示当前进度（3/10）和正确计数
- 所有题目答完后显示结果汇总

**技术实现：** 后端调用 DeepSeek API 基于知识库内容出题，JSON Schema 约束输出格式。

#### 3b. 刷题记录

**用户流程：** 切换到「记录」Tab → 查看历史答题记录 → 展开查看详情

- 筛选条件：知识点下拉、正确/错误/全部切换、日期范围
- 列表展示：知识点标签、题目摘要、对错图标、得分、用时、日期
- 点击展开：完整查看选项对比（绿色正确/红色错误）、正确答案、详细解析
- 分页加载

#### 3c. 错题本

通过「错题本」入口或 `/api/quiz/wrong-questions` 查看：

- 按知识点分类统计，按正确率排序推荐优先复习的知识点
- 展示错误答案、得分、错误时间
- 支持「标记已掌握」移出错题本
- 支持「随机抽题重做」

### 4. 模拟面试 (`/interview`) — 完整面试流程

**用户流程：** 面试列表 → 选择方向配置 → 逐题作答 → 提交 → 生成评估报告

#### Phase 1 — 面试列表
- 展示历史面试会话，三种筛选：全部 / 进行中 / 已完成
- 每个会话显示：方向、难度、题数、状态（未开始/进行中/已完成/已评估）
- 支持继续未完成的面试、查看已完成的报告、删除会话

#### Phase 2 — 面试配置
- 选择面试方向（Java 后端、前端、算法等 10 个预设方向）
- 选择难度，设定题目数量（6-12 题）
- 选择简历关联（可选），AI 会根据简历内容出题

#### Phase 3 — 答题
- 逐题作答，题目分为主题干和追问
- 答题后不立即批改（区别于刷题模式），全部答完才统一评估
- 支持暂存答案、提前交卷
- 支持断点续传

#### Phase 4 — 评估报告
- 总体得分 + 分段评级（优秀/良好/需加强）
- 分类得分（各技术类别分别评分）
- 每题详细反馈和参考解答
- 总体评价、亮点、改进建议

**技术实现：**
- 面试会话在 Redis 中缓存，答题完成后异步调用 LLM 评估
- 面试方向（Skill）系统：预设 10 个方向，每个有分类权重、参考文件、Persona
- 动态追题：基于已答表现自适应调整后续题目分配

### 5. 知识库 (`/knowledge`)

**用户流程：** 查看知识库列表 → 点进详情 → 上传文档

- 知识库是文档的集合，每个知识库可包含多个文档
- 支持格式：PDF、Markdown
- 上传后自动执行文档摄入管线：上传 → 解析（Tika）→ 切片（按标题分块）→ 向量化（BGE-m3）→ 存入 ES
- 文档状态实时展示：上传中/解析中/切片中/向量化/就绪/失败
- 支持查看文档切片详情、删除文档
- OCR 支持：PDF 中的图片自动调用 PaddleOCR 提取文字

### 6. 简历解析 (`/resume`)

**用户流程：** 上传简历 → 自动解析 → 查看结构化结果

- 支持 PDF 格式简历
- 后端提取文本后调用 LLM 解析为结构化 JSON：
  - 按章节分类（技能/经历/项目/教育/证书/自我介绍）
  - 提取技术标签
  - 过滤个人隐私信息
  - 多栏排版自动重排
- 支持重新分析、删除简历
- 简历可在 AI 问答和模拟面试中关联使用

### 7. 用户画像 (`/profile`)

**用户流程：** 查看综合数据面板

- 顶部统计卡片：总答题数、正确率、最长连续正确、待复习数
- 技术栈标签云：从答题和简历中提取
- 技能画像（每个面试方向独立）：
  - LLM 生成的用户能力总结
  - 分类维度掌握度（熟练/掌握/薄弱/未覆盖）
  - 下一阶段学习建议
  - 多个面试方向间切换查看

## 核心业务流程

### 出题流程
```
用户勾选知识库 + 配置参数
  → 后端 VectorRetrievalService 从 ES 检索相关内容
  → 构建 prompt（system + 检索结果 + 用户配置）
  → 调用 DeepSeek API（非流式，temperature=0）
  → 解析 JSON 响应 → 持久化 quiz_question
  → 返回题目列表
```

### AI 问答流程
```
用户发送问题
  → LlmService.queryRewrite（改写为检索友好查询）
  → VectorRetrievalService 混合检索（向量 + BM25）
  → 构建上下文 prompt + 历史消息
  → StreamingChatService 调用 DeepSeek API（SSE 流式）
  → 前端逐块渲染 Markdown
  → 后台异步压缩超出窗口的历史消息
```

### 模拟面试评估流程
```
用户提交全部答案
  → InterviewSessionService 标记 COMPLETED
  → AnswerEvaluationService 异步调用 LLM 评估
  → 生成每题评分 + 反馈 + 参考解答
  → 生成总体评估（亮点/改进/建议）
  → 前端轮询报告就绪状态
  → 展示完整面试报告
```
