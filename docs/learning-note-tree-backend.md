# 学习笔记知识树：存储与升级

## 页面使用

学习笔记详情和聊天中的“存为学习笔记 / 更新这条笔记”共用树编辑器。旧 Markdown 笔记选择“转为知识树”后，原正文完整放入“原笔记”节点；点击保存才写入数据库，取消编辑可恢复转换前的内容。

节点标题和 Markdown 正文可直接编辑，支持添加子节点/同级节点、上下移动、缩进/提升、折叠、搜索、全文阅读和 Markdown 导出。删除分支可以撤销。保存使用现有版本号校验，失败时保留当前草稿。搜索结果开始编辑时退出搜索并展开祖先，避免修改关键词后编辑框消失。

聊天中复制问答会新增“补充问答”根节点；AI 整理结果新增为独立根节点供用户对照，不替换原分支。“将所选原文填入正文”会明确提示将整棵树替换为一个原文节点。原始问答快照始终独立保存。

## 接口合同

现有 `/api/learning-notes` 创建、详情、列表和更新接口增加可选 `treeJson` 字符串。原始问答快照、来源会话、学习状态、权限和版本规则保持原有行为。

```json
{"version":1,"nodes":[{"id":"stable-node-id","title":"知识点","body":"Markdown 解释","children":[]}]}
```

树在保存入口解析为节点结构并校验：节点编号全树唯一且最长 128 字符，标题非空、单行、最长 120 字，正文是字符串，子节点是数组；整棵树至少有一个节点，最多 1000 个节点和 32 层。树 JSON 最长 300000 字符，生成的 Markdown 正文沿用 40000 字符上限。

提交树时，以树为准生成 `content`，忽略请求中的旧正文：根节点使用二级标题，子节点依次加深，超过六级使用加粗标题。正文内容、代码块和表格按原样保留。树与生成正文在同一条带版本条件的 SQL 中保存，正文继续用于搜索和“继续问”上下文。新增树的创建重试身份包含规范化后的树数据，旧纯文本请求的重试身份不变。

旧笔记的 `treeJson` 为 `null`，读取时不会转换或重写。旧客户端更新时，省略树或传 `null`，若正文未变则保留已有树；正文改变则清空树，避免树与正文不一致。要修改树结构应显式提交 `treeJson`。节点折叠、选择状态属于界面状态，不存进笔记内容。

## 数据库升级

新库使用 `ai-rag-agent/knowledge/src/main/resources/schema.sql`。已有库先执行：

```text
ai-rag-agent/knowledge/src/main/resources/migrations/20261116_learning_note_tree.sql
```

该 SQL 为 `learning_note` 添加可空 `tree_json JSON` 列，可重复执行，不更新既有笔记行。GitHub Actions 发布包包含此文件，`deploy/docker/deploy.sh` 在构建成功后、替换后端前执行。迁移失败时不替换运行中的应用；应用健康检查失败可回滚旧版，新增列保留。手动部署需先执行同一 SQL。

## 验证

- `mvn -B -ntp verify`：树与正文一致、结构校验、创建幂等、权限、乐观锁、来源保留、旧客户端兼容以及 HTTP JSON 合同。
- `python ai-rag-agent/tests/verify_database_schema.py`：独立临时 MySQL 8 验证新库、旧库升级、重复迁移、原文保留，以及真实 mapper SQL 的树插入、清空与版本条件更新；不读取业务数据库配置。
- `python3 -m unittest discover -s deploy/tests -v`（Linux/WSL）：部署顺序、迁移失败保留旧应用、健康检查失败回滚、数据卷保留。

上述命令验证本地实现；执行检查不代表已发布到线上。

2026-11-16 本地验证：后端全量 202 项、前端单元 14 项、原有笔记浏览器回归 38 项、树集成浏览器回归 6 项、Linux 部署脚本 6 项通过，前端生产构建通过（保留原有大包和动态导入警告）。浏览器验证包含手机布局、中文组合输入、保存冲突、取消后载入新版本、搜索中继续编辑、原文代码/表格保留。

隔离 MySQL、Redis、Spring 服务还验证了真实 HTTP 创建/更新/重读、搜索、权限、非法树、版本冲突和后端重启后的持久性。`ai-job-prep-frontend/tests/live/learning-note-tree.mjs` 使用本机忽略目录中的临时账号 fixture，验证真实浏览器登录、旧笔记转换、数据库保存和刷新，不 mock 笔记接口；运行需要显式启动指向测试后端的前端服务。测试环境不使用业务数据库或真实模型密钥。
