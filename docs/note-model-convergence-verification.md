## 真实服务验证

使用临时独立账号、真实 Chrome、本机 MySQL/Redis 和现有模型配置，未更改密钥。

3. 另一页面实际更新版本，本地保存收到 409；明确载入最新版本后，正文与快照一致，再保存成功。
4. 从笔记继续问，模型读取当前笔记的任务名和标记；新增队列信息经真实 `MERGE` 合并，来源快照增至六条。注入一次模型 503 与一次保存 503，草稿和来源恢复路径均正确，取消勾选后仍能重试保存。
5. 详情页长文本原生撤销/重做、编辑保存正常。删除原始来源会话后，笔记仍可编辑并查看已保存的原始问答。
6. 独立实库 API 验证创建并发重试只生成一条、同请求不同内容拒绝、跨用户隔离、旧版本保护、当前草稿参与 AI、继续问/更新快照、删除来源和删除笔记后的兼容行为。
